### How to Run

1.  **Quick Start (Default):**

    ```bash
    python main.py
    ```

2.  **Custom Port (Shorthand):**

    ```bash
    python main.py -p 9000
    ```

3.  **Production Mode (Shorthand):**

    ```bash
    python main.py -nr -H 127.0.0.1
    ```

4.  **Debug Mode (Shorthand):**

    ```bash
    python main.py -l debug
    ```

5.  **Combined Shorthands:**
    ```bash
    python main.py -p 8080 -nr -l warning
    ```
